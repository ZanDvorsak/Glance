Before you start

Glance needs two things that are not part of this installer:

1. The display driver
   The USB display (ID 1908:0102) must use the libusb-win32 driver.
   Install it with Zadig (https://zadig.akeo.ie/): select the display, choose "libusb-win32", and click Install Driver.
   This replaces the driver AIDA64 uses for the same display, so AIDA64 will not be able to use it until it is switched back.

2. Sensor access (optional but recommended)
   CPU and motherboard temperatures, fans and voltages need the PawnIO driver (https://pawnio.eu/).
   Without it, Glance still shows GPU, drive, memory and network sensors.

What this installer sets up
   - The Glance service ("Glance display service"), a Windows service that starts with Windows. It reads the hardware
     sensors and drives the display, and turns the display off when Windows shuts down or sleeps. It never opens your
     themes or files.
   - The Glance tray app, which starts when you sign in (you can turn that off on the next page). It draws your saved
     theme with your normal rights and sends it to the service.
   - The Glance editor.

If Glance 0.1 is installed, its background runner is closed and its "start at sign-in" task is removed; the service
replaces both. Your themes and settings are stored in %AppData%\Glance and are kept when you uninstall.
